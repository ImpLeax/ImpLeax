## 🌟 Featured Projects

### 🤖 Advanced Bot Development

* **Smart AI Telegram Bot**
    * **Description:** An intelligent conversational bot powered by cutting-edge AI models for fast and concise responses.
    * **Key Features:** Long-term memory persistence in a PostgreSQL database, and an automated text-summarization engine for older messages to optimize the context window and minimize API token usage.
    * **Stack:** `aiogram 3`, asynchronous SQLAlchemy (`asyncpg`), PostgreSQL, Docker, `docker-compose`.

* **Enterprise Auto Service Management Ecosystem**
    * **Description:** A highly complex Telegram automation system designed to manage workflow operations for a car service center.
    * **Key Features:** Processes incoming customer orders, dynamically creates corresponding dedicated topics within the mechanics' team chat, tracks order statuses, automatically notifies clients upon completion, aggregates business statistics, and includes a comprehensive administrative control panel.
    * **Stack:** Python, Asynchronous Programming, Database Management.

* **Channel Membership & Broadcasting Bot**
    * **Description:** A specialized utility bot to streamline community management and user onboarding.
    * **Key Features:** Automates the verification and acceptance of join requests for Telegram channels alongside an integrated mass-messaging/broadcasting system.

* **Audio Streaming Discord Bot**
    * **Description:** An asynchronous bot built for high-quality audio playback directly inside Discord voice channels.
    * **Key Features:** Features real-time music platform API integrations, playback queue management, and optimized stream data handling using `asyncio`.

* **Business CRM System**
